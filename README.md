# AI 小说写作系统

一个本地运行的长篇小说智能写作助手。Flask 服务端渲染，浏览器打开即用；所有数据以 JSON 文件落盘在本目录，无需数据库。核心思路：把「作品档案、大纲、角色状态、世界观、伏笔、文风、分层记忆」组装成上下文交给 LLM，按「生成 → 审校 → 重写 → 采纳回写」的流水线逐章产出正文。

## 快速开始

```bash
pip3 install flask        # 仅依赖 Flask（markupsafe 随其自带）
python3 app.py
```

然后浏览器打开 <http://127.0.0.1:5001>。

- 默认端口 **5001**（macOS 的 5000 被隔空播放接收器占用）。可用 `WRITER_PORT=8080 python3 app.py` 覆盖。
- 改了代码必须重启进程才生效（后台运行时自动重载是关闭的）：

  ```bash
  pkill -f "python3 app.py"; nohup python3 app.py > /tmp/writer_server.log 2>&1 &
  ```

## 首次使用

1. **模型配置**：左侧「系统 → 模型配置」，为三个槽位（正文生成 / 审校 Critic / 状态抽取·摘要）填 Base URL、API Key、模型名。支持 OpenAI / DeepSeek / Kimi / 通义千问 / 智谱 GLM 预设；填好 Key 后可「拉取模型列表」「测试连接」。审校、抽取两槽默认勾选「与正文生成使用相同配置」，不另填即可。
2. **新书向导**：以对话方式和 LLM 聊四步——作品定位 → 核心创意 → 故事背景 → 文风规范，聊完自动落成作品档案。聊完不满意还能继续对话修改。
3. **角色列表**：向导完成后可一键「LLM 生成主角」；配角可对话创建（聊明白自动建档），也可手动增删改。
4. 之后补全世界观设定库、文风控制（可 LLM 抽取 / 生成范文），即可进写作工作台开写。

## 页面地图

| 页面 | 作用 |
| --- | --- |
| 总览 Dashboard | 项目状态一览：进度、最近摘要、待回收伏笔 |
| 新书向导 | 对话式初始化作品档案（project.json） |
| 写作工作台 | 核心：输入本批概要 → LLM 出 1~20 章细纲 → 确认后逐章「生成→审校→重写」→ 浏览 → 采纳 / 重生成 |
| 审校循环 | 每章的审校记录：问题清单、重写轮次、字数达标情况 |
| 角色列表 | 主角 / 配角档案与动态状态（位置、身体、心理、目标…），支持对话创建与对话调整 |
| 章节大纲 | 多卷管理，每卷章节分页展示；只展示与删除，章节创建在工作台 |
| 分层记忆 | 近章原文 + 逐章摘要层 + 合并摘要层；勾选若干章由 LLM 压缩成合并段，控制 token 成本 |
| 世界观设定库 | 设定条目（力量体系 / 地理 / 势力…），支持 LLM 初始化与扩写 |
| 伏笔追踪 | 埋下 / 回收状态管理，未回收伏笔会注入写作上下文；支持 LLM 头脑风暴 |
| 文风控制 | 文风规范 + 范文样本，LLM 可抽取约束、生成范文 |
| 模型配置 | 三槽位 LLM 配置，key 掩码显示，本地落盘 |

## 数据文件

全部数据在项目根目录的 JSON 文件里（已被 .gitignore 排除）：

| 文件 | 内容 |
| --- | --- |
| `config.json` | 模型配置（含 API Key，**注意保密**） |
| `project.json` | 作品档案（向导产出） |
| `characters.json` | 角色档案与状态 |
| `characters_bck/` | 角色文件自动备份（保留近 1 个月） |
| `outline.json` | 卷 / 章节大纲 |
| `chapters.json` | 已生成章节正文与批次 |
| `memory.json` | 逐章摘要、合并摘要 |
| `bible.json` / `foreshadow.json` / `style.json` | 世界观 / 伏笔 / 文风 |

想重置某块数据，停服后删对应 JSON 再启动即可（会自动重建为空结构）。

## 写作流水线（工作台内部）

1. 输入本批大致内容（如「主角开学军训，认识女主」）与每章最小字数，选生成章数（≤20）。
2. LLM 先出整批细纲，确认后开始逐章生成：上下文 = 作品档案 + 文风 + 主线/本卷摘要/相邻章细纲 + 角色动态状态 + 世界观全量 + 未回收伏笔 + 分层记忆（合并摘要 + 近 5 章摘要 + 上一章正文结尾）。
3. 每章生成后送审校 Critic（一致性 / 逻辑 / 文风 / 字数），不通过自动重写，最多 2 轮。
4. 全部完成后逐章浏览，可对单章 / 多章 / 整批重新生成（可附新要求）。
5. 点「采纳」后自动回写：逐章摘要入库、伏笔状态更新、角色状态变更同步。
